# PlayHub Games

PlayHub Games is a dark neon games hub where you can play free online games instantly in your browser. No download, no sign-up, English only.

**Live website:** https://playhub-games-seven.vercel.app/

## No. 1 Game: Roadster Loop

Roadster Loop is the No. 1 main game on PlayHub Games. It is a full 3D flying car game with DRIVE / FLY / LAND controls, Stunt Run, Free Drive/Fly, Racing vs Ghost, and 4 cities: Night City, Desert Dunes, Coastal Bay, and Snow City.

## Features

- 21 free browser games, playable instantly
- Dark neon design
- No download and no sign-up
- English only
- SEO friendly, with game guides and FAQs
- Mobile and desktop friendly, with on-screen touch buttons on mobile

## Technology

- Single-page website built from `index.html`
- Hosted on Vercel, connected to this GitHub repository (main branch)
